<h2 align="center">Philosophy</h2>

<h3 align="center"><i>Small by design.</i></h3>

<p align="center">
  The Unix way, applied to everything I build:<br />
  less code, fewer moving parts, and systems you can trust.
</p>

```c
#include <stdio.h>

typedef struct {
    const char *handle;
    const char *role;
    const char *based_in;
    const char *stack[4];
    const char *philosophy[4];
    int         years_building;
} Dev;

static const Dev fa11len = {
    .handle         = "Fa11lenDEV",
    .role           = "CTO @ Ninenity",
    .based_in       = "Brazil",
    .stack          = { "C", "C++", "TypeScript", "Linux" },
    .philosophy     = { "Simple first", "Clarity over cleverness",
                        "Secure by default", "Built to last" },
    .years_building = 9, /* and counting */
};

int main(void) {
    printf("%s | %s\n", fa11len.handle, fa11len.role);
    for (int i = 0; i < 4; i++)
        printf("  - %s\n", fa11len.philosophy[i]);
    return 0;
}
```
